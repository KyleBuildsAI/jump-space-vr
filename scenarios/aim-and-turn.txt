# In a level: motion aiming steers the game camera to the controller, snap turning turns the body, the left stick
# moves relative to the body. Starts from the main menu and enters the prologue with the keyboard.

waitfor vrRendering == 1 120
head 0 1.6 0  0 0 0
hand right 0.2 1.3 0.3  0 0 0
recenter
key 0x0D
wait 8
keyuntil 0x1B 4 mainMenu == 1 90
wait 3
key 0x28
key 0x26
key 0x0D
waitfor inLevel == 1 150
# The prologue opens with a wake-up cinematic; look input is locked until it ends.
waitfor cutscene == 1 90
waitfor cutscene == 0 300
wait 5
recenter
wait 2

# The first-person rig sits on the controller: its item locator lands on the grip.
expect weaponInHand == 1
expect itemLocator == 1
expect gripErrorCm < 1
snapshot

# Aim 30 degrees right and 15 degrees up: the game camera must follow.
hand right 0.2 1.4 0.3  -15 30 0
wait 2
expect aimYawOffset == 30 2
expect cameraPitch == 15 2

# Aim back to the centre.
hand right 0.2 1.4 0.3  0 0 0
wait 2
expect aimYawOffset == 0 2
expect cameraPitch == 0 2

# Snap turn right: the camera keeps pointing along the controller relative to the new body yaw.
input right.stick 1 0
wait 0.4
input right.stick 0 0
wait 2
expect aimYawOffset == 0 2

# Left stick forward reaches the game as forward movement (body-relative, aim straight ahead).
input left.stick 0 1
wait 0.5
expect gamepadLeftY > 0.8
input left.stick 0 0
snapshot

# The trigger fires the weapon in gameplay (the laser pointer must not take it).
input right.trigger 1
wait 0.3
expect laserOnPanel == 0
expect rightTrigger > 0.5
input right.trigger 0

# Frame rate in the level with both eyes rendering (mock runtime, so no compositor overhead). 45 fps is the floor
# where Quest reprojection still feels acceptable; aim for the headset's refresh rate.
wait 5
expect fps > 45
log frame time check done
